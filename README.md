### Pre-requirements 📋

_Server apache, php 5.6 >=, mysql_

# Installation

The following steps are meant to be used on a development server.

- Composer optional

```bash
$ composer create-project joncastdev/lead-management
``` 

- Clone Project

```bash
$ git clone https://github.com/jonathancastrodev/lead-management.git
``` 

- Set permissions

```bash
$ sudo chmod -R 777 lead-management
```

- Move to folder

```bash
$ cd /var/www/lead-management
```
- Run migrations

```bash
$ php index.php migrate 
```
